# PART 10 — Write the Lambda code

Now return to:

**Lambda → GenAI-Bedrock-Lambda → Code**

You'll see the inline code editor.

Delete the existing code.

Use this architecture:

```text
import JSON
import boto3
import uuid
from datetime import datetime

create Bedrock client
create DynamoDB client

receive question

send question to Bedrock

receive AI response

save question + answer

return response
```

For the first version, I recommend using the **Bedrock Converse API**, because it gives us a clean interface for model conversations and makes it easier to change models later. AWS's current Bedrock quickstart documents the Converse/Invoke APIs for inference. ([AWS Documentation][10])

A Lambda implementation can look like this:

```python
import json
import boto3
import uuid
from datetime import datetime, timezone

bedrock = boto3.client("bedrock-runtime", region_name="us-east-1")
dynamodb = boto3.resource("dynamodb", region_name="us-east-1")

table = dynamodb.Table("GenAIChatHistory")

MODEL_ID = "amazon.nova-micro-v1:0"


def lambda_handler(event, context):

    try:

        # -----------------------------
        # 1. Get request body
        # -----------------------------

        body = event.get("body")

        if isinstance(body, str):
            body = json.loads(body)

        question = body.get("question", "").strip()

        if not question:
            return {
                "statusCode": 400,
                "headers": {
                    "Content-Type": "application/json",
                    "Access-Control-Allow-Origin": "*"
                },
                "body": json.dumps({
                    "error": "Question is required"
                })
            }

        # -----------------------------
        # 2. Call Amazon Bedrock
        # -----------------------------

        response = bedrock.converse(
            modelId=MODEL_ID,
            messages=[
                {
                    "role": "user",
                    "content": [
                        {
                            "text": question
                        }
                    ]
                }
            ],
            inferenceConfig={
                "maxTokens": 300,
                "temperature": 0.7
            }
        )

        # -----------------------------
        # 3. Extract AI response
        # -----------------------------

        answer = response["output"]["message"]["content"][0]["text"]

        # -----------------------------
        # 4. Save conversation
        # -----------------------------

        session_id = str(uuid.uuid4())

        table.put_item(
            Item={
                "sessionId": session_id,
                "question": question,
                "answer": answer,
                "timestamp": datetime.now(
                    timezone.utc
                ).isoformat()
            }
        )

        # -----------------------------
        # 5. Return result
        # -----------------------------

        return {
            "statusCode": 200,
            "headers": {
                "Content-Type": "application/json",
                "Access-Control-Allow-Origin": "*"
            },
            "body": json.dumps({
                "success": True,
                "question": question,
                "answer": answer
            })
        }

    except Exception as e:

        print("ERROR:", str(e))

        return {
            "statusCode": 500,
            "headers": {
                "Content-Type": "application/json",
                "Access-Control-Allow-Origin": "*"
            },
            "body": json.dumps({
                "success": False,
                "error": str(e)
            })
        }
```

### Important

The exact Bedrock model ID can vary by model/region/account availability.

If:

```text
amazon.nova-micro-v1:0
```

isn't accepted in your console, **don't guess the ID**.

We can get the exact model ID from your Bedrock Model Catalog.

# PART 19 — Connect frontend to API Gateway

Your JavaScript will have:

```javascript
const API_URL =
    "YOUR_API_GATEWAY_URL/ask";
```

For example:

```javascript
const API_URL =
    "https://abc123.execute-api.us-east-1.amazonaws.com/ask";
```

Then:

```javascript
async function askAI() {

    const question =
        document.getElementById("question").value;

    const response =
        await fetch(API_URL, {

            method: "POST",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify({
                question: question
            })
        });

    const data =
        await response.json();

    document.getElementById("answer")
        .innerText = data.answer;
}
```

# PART 20 — CORS

This is a very common problem.

Your architecture is:

```text
S3 Website
     |
     | different domain
     v
API Gateway
```

The browser can block the request because of **CORS**.

In API Gateway, configure CORS for:

```text
Allowed origins:
*
```

For learning/testing.

Allowed methods:

```text
POST
OPTIONS
```

Allowed headers:

```text
Content-Type
```

For production, don't use `*`; specify your actual frontend domain.

# PART 24 — Add conversation memory

Currently each request is independent.

We can make it a real chatbot.

Instead of:

```text
Question
   ↓
Bedrock
```

we'll have:

```text
Conversation
     |
     v
DynamoDB
     |
     v
Lambda
     |
     v
Previous messages
     +
Current question
     |
     v
Bedrock
```

Example:

User:

```text
What is Lambda?
```

AI:

```text
AWS Lambda is...
```

User:

```text
What are its advantages?
```

Lambda retrieves the previous conversation:

```text
User:
What is Lambda?

AI:
AWS Lambda is...

User:
What are its advantages?
```

and sends the conversation to Bedrock.

Then the AI understands that **"its" means Lambda**.

This makes the project much more impressive.

# PART 29 — Security architecture

Eventually we want:

```text
                  USER
                    |
                    v
               CloudFront
                    |
                    v
                S3 Private
                    |
                    v
                 Cognito
                    |
                    v
               API Gateway
                    |
                    v
                 Lambda
                 /     \
                /       \
               v         v
          Bedrock     DynamoDB
```

IAM controls:

```text
Lambda
 ├── Bedrock permission
 └── DynamoDB permission
```

```text

```

```text
HTML
JavaScript
React
S3
```
